# Engineering milestones

1. Foundation — Android project, branding, onboarding, workspace choice, CI.
2. Runtime — executable bootstrap, package manifests, process service, PTY terminal.
3. Workspace — POSIX internal projects, external folder synchronization, full file manager.
4. Editor — high-performance source editor, search, LSP, diagnostics and project intelligence.
5. Git/GitHub — full Git operations, GitHub sign-in, clone/publish/push workflows.
6. Extensions — extension host, permissions, themes and VSIX/Open VSX compatibility.
7. Codex — Codex-native agent integration with workspace/runtime/build tools.
8. Debug/preview — DAP, ports, localhost preview, process management.
9. Hardening/release — lifecycle recovery, tests, performance, security review, signing and release.
